자주 묻는 질문 (FAQ)

스픽 프리미엄 플러스는 무엇인가요?

스픽 프리미엄 플러스는 기존 프리미엄 플랜의 업그레이드 버전으로, 무제한 AI 대화, 고급 AI 모델 사용, 우선 고객 지원, 베타 기능 조기 접근 등의 혜택을 제공하는 프리미엄 서비스입니다. 더 자세한 정보는 소개 페이지에서 확인하실 수 있습니다.

프리미엄과 프리미엄 플러스의 차이점은 무엇인가요?

주요 차이점은 AI 튜터 사용량(월간 제한 vs 무제한), AI 모델 수준(기본 vs 고급), 맞춤형 학습 기능(일부 vs 풀 제공), 30일 습관 형성 프로그램 포함 여부입니다. 공식 공개 판매 페이지의 첫 1년 가격은 프리미엄 129,000원, 프리미엄 플러스 239,000원으로 연간 110,000원 차이입니다. 이후에는 기본 할인가로 연 단위 청구되며 정확한 갱신 금액은 구매 화면에서 확인하세요.

할인코드는 어떻게 사용하나요?

현재 안내하는 파트너 할인은 전용 링크로 웹 구매 화면에 들어가면 자동 적용되는 방식입니다. 공용 입력 문자열을 복사하는 혜택이나 인앱 결제용 할인코드가 아닙니다. 공식 6자리 프로모션 등록은 별도로 발급받은 이용권을 활성화하는 기능입니다. 할인코드 페이지의 안내와 실제 결제 금액을 확인해주세요.

여러 할인코드를 동시에 사용할 수 있나요?

플러스 파트너 안내의 60,000원은 연간 299,000원에서 239,000원으로 내려가는 추가 할인입니다. 이미 표시된 239,000원에서 다시 빼지 않습니다. 다른 파트너나 친구 초대 할인까지 합산할 근거는 없으며 친구 초대는 다른 프로모션 링크 구매를 제외합니다. 할인코드 모음과 구매 경로별 최종 금액을 확인하세요.

친구 초대 할인은 어떻게 받나요?

친구가 공유한 초대 링크로 신규 가입하고 7일 안에 연간권을 웹 결제하면 20,000원 할인 대상입니다. 기존 계정 로그인, 앱 가입·무료체험 구매, 스토어 결제 이력과 다른 프로모션 링크 구매는 제외됩니다. 추천인의 별도 리워드는 구매자 할인액에 합산하지 않습니다.

연간 구독 시 혜택은 무엇인가요?

공식 판매 페이지의 프리미엄 연간 129,000원은 월 환산 10,750원, 플러스 연간 239,000원은 월 환산 약 19,917원입니다. 12개월 총액을 나눈 비교값이므로 월간 구독료나 실제 할부 청구액과는 다릅니다. 첫 1년 이후 갱신 금액과 할부 조건은 결제 화면에서 확인하세요.

신규 사용자 할인은 언제까지 받을 수 있나요?

파트너 할인은 신규 가입·첫 구매 중심으로 안내되지만 전체 경로에 공통인 기존 회원·재구독 제한과 종료일은 확인되지 않았습니다. 친구 초대의 가입 후 7일 조건을 모든 파트너 할인에 적용하지 않습니다. 로그인 후 대상 요금제와 실제 할인가를 확인하세요.

할인코드가 적용되지 않는 이유는 무엇인가요?

할인코드가 적용되지 않는 이유는 만료되었거나, 사용 조건에 맞지 않거나, 중복 할인 불가 조건 때문일 수 있습니다. 각 할인코드의 상세 조건과 유효기간을 확인해보세요.

스픽 프리미엄 플러스는 언제 해지할 수 있나요?
